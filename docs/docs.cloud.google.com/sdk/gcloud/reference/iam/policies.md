NAME

gcloud iam policies - manage IAM deny policies

SYNOPSIS

`gcloud iam policies` [`COMMAND`](https://docs.cloud.google.com/sdk/gcloud/reference/iam/policies#COMMAND) \[ [`GCLOUD_WIDE_FLAG`](https://docs.cloud.google.com/sdk/gcloud/reference/iam/policies#GCLOUD-WIDE-FLAGS)` …` \]

DESCRIPTION

Commands for managing Google Cloud IAM deny policies.

GCLOUD WIDE FLAGS

These flags are available to all commands: [`--help`](https://docs.cloud.google.com/sdk/gcloud/reference#--help) .

Run `$ `[`gcloud help`](https://docs.cloud.google.com/sdk/gcloud/reference) for details.

COMMANDS

`COMMAND` is one of the following:

[`create`](https://docs.cloud.google.com/sdk/gcloud/reference/iam/policies/create)  
Create a policy on the given attachment point with the given name.

[`delete`](https://docs.cloud.google.com/sdk/gcloud/reference/iam/policies/delete)  
Delete a policy on the given attachment point with the given name.

[`get`](https://docs.cloud.google.com/sdk/gcloud/reference/iam/policies/get)  
Get a policy on the given attachment point with the given name.

[`list`](https://docs.cloud.google.com/sdk/gcloud/reference/iam/policies/list)  
List the policies on the given attachment point.

[`update`](https://docs.cloud.google.com/sdk/gcloud/reference/iam/policies/update)  
Update the policy on the given attachment point with the given name.

NOTES

These variants are also available:

```
gcloud alpha iam policies
```

```
gcloud beta iam policies
```
