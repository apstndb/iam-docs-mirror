NAME

gcloud iam workforce-pools providers - create and manage workforce pool providers

SYNOPSIS

`gcloud iam workforce-pools providers` [`GROUP`](https://docs.cloud.google.com/sdk/gcloud/reference/iam/workforce-pools/providers#GROUP) \| [`COMMAND`](https://docs.cloud.google.com/sdk/gcloud/reference/iam/workforce-pools/providers#COMMAND) \[ [`GCLOUD_WIDE_FLAG`](https://docs.cloud.google.com/sdk/gcloud/reference/iam/workforce-pools/providers#GCLOUD-WIDE-FLAGS)` …` \]

DESCRIPTION

The gcloud iam workforce-pools providers group lets you create and manage workforce pool providers.

GCLOUD WIDE FLAGS

These flags are available to all commands: [`--help`](https://docs.cloud.google.com/sdk/gcloud/reference#--help) .

Run `$ `[`gcloud help`](https://docs.cloud.google.com/sdk/gcloud/reference) for details.

GROUPS

`GROUP` is one of the following:

[`keys`](https://docs.cloud.google.com/sdk/gcloud/reference/iam/workforce-pools/providers/keys)  
Create and manage IAM workforce pool provider keys.

[`operations`](https://docs.cloud.google.com/sdk/gcloud/reference/iam/workforce-pools/providers/operations)  
Manage IAM workforce pool provider long-running operations.

[`scim-tenants`](https://docs.cloud.google.com/sdk/gcloud/reference/iam/workforce-pools/providers/scim-tenants)  
Manage IAM workforce identity pool provider SCIM tenants.

COMMANDS

`COMMAND` is one of the following:

[`create-oidc`](https://docs.cloud.google.com/sdk/gcloud/reference/iam/workforce-pools/providers/create-oidc)  
Create a new OIDC workforce pool provider.

[`create-saml`](https://docs.cloud.google.com/sdk/gcloud/reference/iam/workforce-pools/providers/create-saml)  
Create a new SAML workforce pool provider.

[`delete`](https://docs.cloud.google.com/sdk/gcloud/reference/iam/workforce-pools/providers/delete)  
Delete a workforce pool provider.

[`describe`](https://docs.cloud.google.com/sdk/gcloud/reference/iam/workforce-pools/providers/describe)  
Describe a workforce pool provider.

[`list`](https://docs.cloud.google.com/sdk/gcloud/reference/iam/workforce-pools/providers/list)  
List workforce pool providers.

[`undelete`](https://docs.cloud.google.com/sdk/gcloud/reference/iam/workforce-pools/providers/undelete)  
Undelete a workforce pool provider.

[`update-oidc`](https://docs.cloud.google.com/sdk/gcloud/reference/iam/workforce-pools/providers/update-oidc)  
Update an OIDC workforce pool provider.

[`update-saml`](https://docs.cloud.google.com/sdk/gcloud/reference/iam/workforce-pools/providers/update-saml)  
Update a new SAML workforce pool provider.

NOTES

These variants are also available:

```
gcloud alpha iam workforce-pools providers
```

```

```
