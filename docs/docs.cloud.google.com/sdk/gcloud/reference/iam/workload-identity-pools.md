NAME

gcloud iam workload-identity-pools - manage IAM workload identity pools

SYNOPSIS

`gcloud iam workload-identity-pools` [`GROUP`](https://docs.cloud.google.com/sdk/gcloud/reference/iam/workload-identity-pools#GROUP) \| [`COMMAND`](https://docs.cloud.google.com/sdk/gcloud/reference/iam/workload-identity-pools#COMMAND) \[ [`GCLOUD_WIDE_FLAG`](https://docs.cloud.google.com/sdk/gcloud/reference/iam/workload-identity-pools#GCLOUD-WIDE-FLAGS)` …` \]

DESCRIPTION

Commands for managing IAM workload identity pools.

GCLOUD WIDE FLAGS

These flags are available to all commands: [`--help`](https://docs.cloud.google.com/sdk/gcloud/reference#--help) .

Run `$ `[`gcloud help`](https://docs.cloud.google.com/sdk/gcloud/reference) for details.

GROUPS

`GROUP` is one of the following:

[`managed-identities`](https://docs.cloud.google.com/sdk/gcloud/reference/iam/workload-identity-pools/managed-identities)  
Manage IAM workload identity pool managed identities.

[`namespaces`](https://docs.cloud.google.com/sdk/gcloud/reference/iam/workload-identity-pools/namespaces)  
Manage IAM workload identity pool namespaces.

[`operations`](https://docs.cloud.google.com/sdk/gcloud/reference/iam/workload-identity-pools/operations)  
Manage IAM workload identity pool long running operations.

[`providers`](https://docs.cloud.google.com/sdk/gcloud/reference/iam/workload-identity-pools/providers)  
Manage IAM workload identity pool providers.

COMMANDS

`COMMAND` is one of the following:

[`add-attestation-rule`](https://docs.cloud.google.com/sdk/gcloud/reference/iam/workload-identity-pools/add-attestation-rule)  
Add an attestation rule on a workload identity pool.

[`add-iam-policy-binding`](https://docs.cloud.google.com/sdk/gcloud/reference/iam/workload-identity-pools/add-iam-policy-binding)  
Add IAM policy binding for a workload identity pool.

[`create`](https://docs.cloud.google.com/sdk/gcloud/reference/iam/workload-identity-pools/create)  
Create a new workload identity pool.

[`create-cred-config`](https://docs.cloud.google.com/sdk/gcloud/reference/iam/workload-identity-pools/create-cred-config)  
Create a configuration file for generated credentials.

[`delete`](https://docs.cloud.google.com/sdk/gcloud/reference/iam/workload-identity-pools/delete)  
Delete a workload identity pool.

[`describe`](https://docs.cloud.google.com/sdk/gcloud/reference/iam/workload-identity-pools/describe)  
Describe a workload identity pool.

[`get-iam-policy`](https://docs.cloud.google.com/sdk/gcloud/reference/iam/workload-identity-pools/get-iam-policy)  
Get the IAM policy for a workload identity pool.

[`list`](https://docs.cloud.google.com/sdk/gcloud/reference/iam/workload-identity-pools/list)  
List workload identity pools.

[`list-attestation-rules`](https://docs.cloud.google.com/sdk/gcloud/reference/iam/workload-identity-pools/list-attestation-rules)  
List the attestation rules on a workload identity pool.

[`remove-attestation-rule`](https://docs.cloud.google.com/sdk/gcloud/reference/iam/workload-identity-pools/remove-attestation-rule)  
Remove an attestation rule on a workload identity pool.

[`remove-iam-policy-binding`](https://docs.cloud.google.com/sdk/gcloud/reference/iam/workload-identity-pools/remove-iam-policy-binding)  
Remove IAM policy binding from a workload identity pool.

[`set-attestation-rules`](https://docs.cloud.google.com/sdk/gcloud/reference/iam/workload-identity-pools/set-attestation-rules)  
Set attestation rules on a workload identity pool.

[`set-iam-policy`](https://docs.cloud.google.com/sdk/gcloud/reference/iam/workload-identity-pools/set-iam-policy)  
Set the IAM policy for a workload identity pool.

[`undelete`](https://docs.cloud.google.com/sdk/gcloud/reference/iam/workload-identity-pools/undelete)  
Undelete a workload identity pool.

[`update`](https://docs.cloud.google.com/sdk/gcloud/reference/iam/workload-identity-pools/update)  
Update a workload identity pool.
