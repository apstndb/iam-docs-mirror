NAME

gcloud iam roles - create and manipulate roles

SYNOPSIS

`gcloud iam roles` [`COMMAND`](https://docs.cloud.google.com/sdk/gcloud/reference/iam/roles#COMMAND) \[ [`GCLOUD_WIDE_FLAG`](https://docs.cloud.google.com/sdk/gcloud/reference/iam/roles#GCLOUD-WIDE-FLAGS)` …` \]

DESCRIPTION

Create and manipulate roles.

GCLOUD WIDE FLAGS

These flags are available to all commands: [`--help`](https://docs.cloud.google.com/sdk/gcloud/reference#--help) .

Run `$ `[`gcloud help`](https://docs.cloud.google.com/sdk/gcloud/reference) for details.

COMMANDS

`COMMAND` is one of the following:

[`copy`](https://docs.cloud.google.com/sdk/gcloud/reference/iam/roles/copy)  
Create a role from an existing role.

[`create`](https://docs.cloud.google.com/sdk/gcloud/reference/iam/roles/create)  
Create a custom role for a project or an organization.

[`delete`](https://docs.cloud.google.com/sdk/gcloud/reference/iam/roles/delete)  
Delete a custom role from an organization or a project.

[`describe`](https://docs.cloud.google.com/sdk/gcloud/reference/iam/roles/describe)  
Show metadata for a role.

[`list`](https://docs.cloud.google.com/sdk/gcloud/reference/iam/roles/list)  
List predefined roles, or the custom roles for an organization or project.

[`undelete`](https://docs.cloud.google.com/sdk/gcloud/reference/iam/roles/undelete)  
Undelete a custom role from an organization or a project.

[`update`](https://docs.cloud.google.com/sdk/gcloud/reference/iam/roles/update)  
Update an IAM custom role.

NOTES

These variants are also available:

```
gcloud alpha iam roles
```

```
gcloud beta iam roles
```
