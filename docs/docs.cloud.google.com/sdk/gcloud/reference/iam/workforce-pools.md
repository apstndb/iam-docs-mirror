NAME

gcloud iam workforce-pools - create and manage workforce pools

SYNOPSIS

`gcloud iam workforce-pools` [`GROUP`](https://docs.cloud.google.com/sdk/gcloud/reference/iam/workforce-pools#GROUP) \| [`COMMAND`](https://docs.cloud.google.com/sdk/gcloud/reference/iam/workforce-pools#COMMAND) \[ [`GCLOUD_WIDE_FLAG`](https://docs.cloud.google.com/sdk/gcloud/reference/iam/workforce-pools#GCLOUD-WIDE-FLAGS)` …` \]

DESCRIPTION

The gcloud iam workforce-pools group lets you create and manage workforce pools for organizations on the Google Cloud Platform.

GCLOUD WIDE FLAGS

These flags are available to all commands: [`--help`](https://docs.cloud.google.com/sdk/gcloud/reference#--help) .

Run `$ `[`gcloud help`](https://docs.cloud.google.com/sdk/gcloud/reference) for details.

GROUPS

`GROUP` is one of the following:

[`operations`](https://docs.cloud.google.com/sdk/gcloud/reference/iam/workforce-pools/operations)  
Manage IAM workforce pool long-running operations.

[`providers`](https://docs.cloud.google.com/sdk/gcloud/reference/iam/workforce-pools/providers)  
Create and manage workforce pool providers.

[`subjects`](https://docs.cloud.google.com/sdk/gcloud/reference/iam/workforce-pools/subjects)  
Create and manage workforce pool subjects.

COMMANDS

`COMMAND` is one of the following:

[`create`](https://docs.cloud.google.com/sdk/gcloud/reference/iam/workforce-pools/create)  
Create a new workforce pool under an organization.

[`create-cred-config`](https://docs.cloud.google.com/sdk/gcloud/reference/iam/workforce-pools/create-cred-config)  
Create a configuration file for generated credentials.

[`create-login-config`](https://docs.cloud.google.com/sdk/gcloud/reference/iam/workforce-pools/create-login-config)  
Create a login configuration file to enable sign-in via a web-based authorization flow using Workforce Identity Federation.

[`delete`](https://docs.cloud.google.com/sdk/gcloud/reference/iam/workforce-pools/delete)  
Delete a workforce pool.

[`describe`](https://docs.cloud.google.com/sdk/gcloud/reference/iam/workforce-pools/describe)  
Describe a workforce pool.

[`get-iam-policy`](https://docs.cloud.google.com/sdk/gcloud/reference/iam/workforce-pools/get-iam-policy)  
Get the IAM policy for a workforce pool.

[`list`](https://docs.cloud.google.com/sdk/gcloud/reference/iam/workforce-pools/list)  
List the workforce pools for an organization.

[`set-iam-policy`](https://docs.cloud.google.com/sdk/gcloud/reference/iam/workforce-pools/set-iam-policy)  
Set the IAM policy for a workforce pool.

[`undelete`](https://docs.cloud.google.com/sdk/gcloud/reference/iam/workforce-pools/undelete)  
Undelete a workforce pool.

[`update`](https://docs.cloud.google.com/sdk/gcloud/reference/iam/workforce-pools/update)  
Update a workforce pool.
