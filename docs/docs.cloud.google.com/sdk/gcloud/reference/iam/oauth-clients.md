NAME

gcloud iam oauth-clients - create and manage OAuth clients

SYNOPSIS

`gcloud iam oauth-clients` [`GROUP`](https://docs.cloud.google.com/sdk/gcloud/reference/iam/oauth-clients#GROUP) \| [`COMMAND`](https://docs.cloud.google.com/sdk/gcloud/reference/iam/oauth-clients#COMMAND) \[ [`GCLOUD_WIDE_FLAG`](https://docs.cloud.google.com/sdk/gcloud/reference/iam/oauth-clients#GCLOUD-WIDE-FLAGS)` …` \]

DESCRIPTION

The gcloud iam oauth-clients group lets you create and manage OAuth clients for projects on the Google Cloud Platform.

GCLOUD WIDE FLAGS

These flags are available to all commands: [`--help`](https://docs.cloud.google.com/sdk/gcloud/reference#--help) .

Run `$ `[`gcloud help`](https://docs.cloud.google.com/sdk/gcloud/reference) for details.

GROUPS

`GROUP` is one of the following:

[`credentials`](https://docs.cloud.google.com/sdk/gcloud/reference/iam/oauth-clients/credentials)  
Create and manage OAuth client credentials.

COMMANDS

`COMMAND` is one of the following:

[`create`](https://docs.cloud.google.com/sdk/gcloud/reference/iam/oauth-clients/create)  
Create an OAuth client.

[`delete`](https://docs.cloud.google.com/sdk/gcloud/reference/iam/oauth-clients/delete)  
Delete an OAuth client.

[`describe`](https://docs.cloud.google.com/sdk/gcloud/reference/iam/oauth-clients/describe)  
Describe an OAuth client.

[`list`](https://docs.cloud.google.com/sdk/gcloud/reference/iam/oauth-clients/list)  
List OAuth clients.

[`undelete`](https://docs.cloud.google.com/sdk/gcloud/reference/iam/oauth-clients/undelete)  
Undelete an OAuth client.

[`update`](https://docs.cloud.google.com/sdk/gcloud/reference/iam/oauth-clients/update)  
Update an OAuth client.

NOTES

This variant is also available:

```
gcloud alpha iam oauth-clients
```
