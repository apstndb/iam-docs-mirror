NAME

SYNOPSIS

`gcloud iam workload-identity-pools managed-identities` [`GROUP`](https://docs.cloud.google.com/sdk/gcloud/reference/iam/workload-identity-pools/managed-identities#GROUP) \| [`COMMAND`](https://docs.cloud.google.com/sdk/gcloud/reference/iam/workload-identity-pools/managed-identities#COMMAND) \[ [`GCLOUD_WIDE_FLAG`](https://docs.cloud.google.com/sdk/gcloud/reference/iam/workload-identity-pools/managed-identities#GCLOUD-WIDE-FLAGS)` …` \]

DESCRIPTION

Commands for managing IAM workload identity pool managed identities.

These flags are available to all commands: [`--help`](https://docs.cloud.google.com/sdk/gcloud/reference#--help) .
