## Resource

There is no persistent data associated with this resource.

| Methods                                                                                                                                    |                                                                    |
|--------------------------------------------------------------------------------------------------------------------------------------------|--------------------------------------------------------------------|
| [`generateAccessToken`](https://docs.cloud.google.com/iam/docs/reference/credentials/rest/v1/projects.serviceAccounts/generateAccessToken) | Generates an OAuth 2.0 access token for a service account.         |
| [`generateIdToken`](https://docs.cloud.google.com/iam/docs/reference/credentials/rest/v1/projects.serviceAccounts/generateIdToken)         | Generates an OpenID Connect ID token for a service account.        |
| [`getAllowedLocations`](https://docs.cloud.google.com/iam/docs/reference/credentials/rest/v1/projects.serviceAccounts/getAllowedLocations) | Returns the trust boundary info for a given service account.       |
| [`signBlob`](https://docs.cloud.google.com/iam/docs/reference/credentials/rest/v1/projects.serviceAccounts/signBlob)                       | Signs a blob using a service account's system-managed private key. |
| [`signJwt`](https://docs.cloud.google.com/iam/docs/reference/credentials/rest/v1/projects.serviceAccounts/signJwt)                         | Signs a JWT using a service account's system-managed private key.  |
