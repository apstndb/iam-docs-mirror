The Policy Analyzer MCP tools are part of the [Cloud Asset Inventory MCP server](https://docs.cloud.google.com/asset-inventory/docs/reference/mcp) . You can view the reference documentation for these MCP tools in the Cloud Asset Inventory documentation:

  - [`analyze_iam_policy`](https://docs.cloud.google.com/asset-inventory/docs/reference/mcp/tools_list/analyze_iam_policy)
  - [`export_iam_analysis_results`](https://docs.cloud.google.com/asset-inventory/docs/reference/mcp/tools_list/export_iam_analysis_results)
  - [`get_iam_policy_analysis_status`](https://docs.cloud.google.com/asset-inventory/docs/reference/mcp/tools_list/get_iam_policy_analysis_status)

To learn how to use the Policy Analyzer MCP tools, see [Use the Policy Analyzer remote MCP server](https://docs.cloud.google.com/policy-intelligence/docs/use-policy-analyzer-mcp) .
